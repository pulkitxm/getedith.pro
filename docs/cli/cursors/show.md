# `ed cursors show`

[`ed cursors`](./README.md)

[The `ed` command line](../README.md)

```bash
ed cursors show ID [--json]
```

Shows one pack from the pack list: its name, family, colours, tags, summary and whether it is applied. It prints details only, never the pack's art, and does not download the pack. An unknown id exits with a not found error.
