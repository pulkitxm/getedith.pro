# `ed emoji-picker forget`

Forgets one frequently used emoji.

[`ed emoji-picker`](./README.md)

Usage:

```
ed emoji-picker forget <emoji> [--json]
```

The argument is a character, a name, or a code point, the same as `ed emoji-picker insert`. Other ledger entries stay.

Examples:

```
ed emoji-picker forget 1F600
ed emoji-picker forget 1F600 --json
```
