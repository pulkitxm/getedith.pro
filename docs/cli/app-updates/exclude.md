# `ed app-updates exclude`

Stops offering updates for one bundle identifier.

[`ed app-updates`](./README.md)

Usage:

```
ed app-updates exclude <bundle-id> [--json]
```

Examples:

```
ed app-updates exclude com.example.App
ed app-updates exclude com.example.App --json
```
