# `ed site-audit stop`

[`ed site-audit`](./README.md)

[The `ed` command line](../README.md)

```bash
ed site-audit stop <id> [--yes] [--json]
```

Previews the running audit that would be cancelled. `--yes` cancels that background task. Without `--yes` nothing is stopped. A project with no running audit is an error.
